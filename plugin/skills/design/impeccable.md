# IMPECCABLE DESIGN VOCABULARY & WORKFLOWS (pbakaus/impeccable)

## 1. Overview
Impeccable by Paul Bakaus establishes a professional design vocabulary and evaluation methodology for AI coding agents, elevating interfaces to production-grade craft.

## 2. The 24 Command Implementations

```markdown
1.  /impeccable shape     -> Map information architecture, density, and flow prior to code.
2.  /impeccable init      -> Analyze codebase and generate/maintain PRODUCT.md context.
3.  /impeccable bolder    -> Inject visual confidence, higher contrast, and dynamic typography.
4.  /impeccable quieter   -> Strip excess sensory noise, calm overly bright accents.
5.  /impeccable distill   -> Prune unnecessary UI widgets, borders, and decorative clutter.
6.  /impeccable colorize  -> Infuse intentional chromatic warmth and tone into drab grayscale.
7.  /impeccable typeset   -> Fix line lengths (45-75 chars), line heights (1.4-1.6), and hierarchy.
8.  /impeccable layout    -> Enforce 4px/8px grid alignment, eliminate visual drifting.
9.  /impeccable animate   -> Add fluid micro-interactions and tactile state transitions.
10. /impeccable delight   -> Introduce tasteful craft moments, pleasant hover feedback.
11. /impeccable overdrive -> Apply advanced graphics (smooth physics, canvas shaders).
12. /impeccable critique  -> Run rigorous 10-heuristic UX evaluation scored out of 40.
13. /impeccable audit    -> Audit accessibility, responsive layout, performance (P0-P3).
14. /impeccable polish    -> Micro-refinement: 1px alignments, token compliance, clean edges.
15. /impeccable harden    -> Edge-case testing: multi-line overflow, empty states, network errors.
16. /impeccable clarify   -> Rewrite confusing labels, button verbs, and error guidance.
17. /impeccable adapt     -> Seamless fluid adaptation from 360px mobile to 1920px desktop.
18. /impeccable optimize  -> Streamline DOM nodes, CSS specificity, and rendering layers.
19. /impeccable onboard   -> Engineer first-time user experience and onboarding flows.
20. /impeccable live      -> Dev-server hot-reloading browser overlay for live inspection.
21. /impeccable generate  -> Produce multiple component variations for review.
22. /impeccable document  -> Capture visual truth and design tokens into DESIGN.md.
23. /impeccable extract   -> Consolidate duplicated styles into shared component tokens.
24. /impeccable craft     -> Direct request handler compiling components to specifications.
```

## 3. Scored Heuristic Critique Protocol
Impeccable evaluates UIs against Jakob Nielsen's 10 Usability Heuristics, scoring each from 1 (unusable) to 4 (impeccable), totaling up to 40 points:
- System Status Visibility (1-4)
- System vs. Real World Match (1-4)
- User Control & Freedom (1-4)
- Consistency & Standards (1-4)
- Error Prevention (1-4)
- Recognition Over Recall (1-4)
- Flexibility & Efficiency (1-4)
- Aesthetic & Minimalist Design (1-4)
- Error Diagnosis & Recovery (1-4)
- Help & Documentation (1-4)

Passing threshold for Quality Gate G4: Score ≥ 32/40 with zero P0/P1 defects.
