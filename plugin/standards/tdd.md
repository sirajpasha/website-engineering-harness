# ENGINEERING STANDARD: TEST-DRIVEN DEVELOPMENT

## Standards
1. **Red-Green-Refactor:** Confirm test failure before writing production code.
2. **Deterministic Suites:** Tests must be completely isolated and deterministic.
3. **Traceability:** Test suites must annotate verified requirement IDs (`REQ-XXX`).
4. **Behavioral Testing:** Test observable user interactions and DOM outputs, not private implementation variables.
