# ENGINEERING STANDARD: USER EXPERIENCE & USABILITY

## Standards
1. **Nielsen's 10 Heuristics:** Layouts evaluated against Jakob Nielsen's usability heuristics (scored ≥ 32/40).
2. **Component States:** Every interactive component must define 5 states: default, hover, active, focus-visible, and disabled.
3. **Cognitive Load:** Keep essential actions clear and unambiguous; avoid unnecessary visual clutter.
4. **Error Prevention & Recovery:** Form inputs must provide clear inline validation with actionable error messages.
