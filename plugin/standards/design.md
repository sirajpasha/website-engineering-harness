# ENGINEERING STANDARD: VISUAL DESIGN & TASTE

## Standards
1. **Anti-Slop Enforcement:** Zero default AI layouts (no repetitive 3-card grids, no unmotivated purple gradients).
2. **Design Tokens:** All colors, typography, spacing, and shadows must be defined in `DESIGN_TOKENS.json`.
3. **Contrast:** High visual contrast with intentional 60-30-10 color ratio.
4. **Typographic Pairing:** Thoughtful font pairing with fluid clamp sizing.
