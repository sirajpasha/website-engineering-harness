# ENGINEERING STANDARD: ACCESSIBILITY (WCAG 2.2 AA)

## Standards
1. **Contrast Ratio:** Normal text ≥ 4.5:1; large text and UI boundaries ≥ 3.0:1.
2. **Keyboard Operability:** 100% of interactive controls operable via keyboard without mouse.
3. **Focus States:** Prominent, high-contrast `:focus-visible` indicators.
4. **Form Labels:** Every form input has an explicitly associated `<label>` element.
5. **Modal Focus Management:** Modals trap focus while active and restore focus upon dismissal.
