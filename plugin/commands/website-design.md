# COMMAND: /website-design

## Description
Activates AGENT 04 (Design Art Director) using Taste Skill to establish visual identity, typographic pairings, color systems, and anti-slop rules.

## Invocations
- Claude Code: `/website-design`
- Terminal / Node: `node scripts/website-engineering-harness-cli.js design`

## Workflow Steps
1. Ingest requirements and sitemap.
2. Select distinctive, brand-tailored font pairing (Display, Body, Monospace).
3. Formulate 60-30-10 color palette with high-contrast accents in `DESIGN_TOKENS.json`.
4. Define spacing scale, radii, and border styles.
5. Compile comprehensive visual narrative in `DESIGN_DIRECTION.md`.
6. Enforce Quality Gate G3 (Design Direction).
