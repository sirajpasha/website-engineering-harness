# DOMAIN GLOSSARY: AETHER STUDIO

- **Studio Estimator:** The interactive configuration widget that calculates estimated engineering sprints based on page count and motion tier.
- **Surface Canvas:** The primary high-contrast background canvas (`#0b0c10` dark obsidian).
- **Audit Request:** A structured form inquiry submitted by a prospective client requesting an autonomous code and design audit.
- **Anti-Slop Standard:** The set of design constraints preventing generic SaaS tropes (e.g. unmotivated radial gradients, floating icon cards).
