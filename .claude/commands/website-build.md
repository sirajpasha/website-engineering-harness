# COMMAND: /website-build

## Description
Activates AGENT 08 (Frontend Architect) and AGENT 09 (Website Implementation Engineer) to implement frontend architecture, component hierarchy, layouts, and pages according to approved designs and standards.

## Invocations
- Claude Code: `/website-build`
- Terminal / Node: `node scripts/harness-cli.js build`

## Workflow Steps
1. Verify Gates G1 through G6 have passed.
2. Generate modular component hierarchy conforming to `COMPONENT_INVENTORY.md`.
3. Implement semantic HTML structure and CSS variables mapped to `DESIGN_TOKENS.json`.
4. Implement interactive controls with genuine state transitions (no no-op handlers).
5. Link implemented files to requirement IDs in `TEST_TRACEABILITY_MATRIX.md`.
