# ENGINEERING STANDARD: BROWSER QA & AUTOMATION

## Standards
1. **6 Viewports:** Validated across `360x800`, `390x844`, `768x1024`, `1024x768`, `1440x900`, `1920x1080`.
2. **Zero Horizontal Overflow:** `scrollWidth <= clientWidth` on all standard views.
3. **Touch Targets:** Minimum 44x44px touch targets on mobile viewports.
4. **Console Cleanliness:** Zero unhandled JavaScript errors or failed 4xx/5xx network asset requests.
