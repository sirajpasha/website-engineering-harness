# ENGINEERING STANDARD: SEARCH ENGINE OPTIMIZATION

## Standards
1. **Metadata:** Unique `<title>` (50-60 chars) and `<meta name="description">` (140-160 chars) per route.
2. **Social Graph:** Open Graph (`og:title`, `og:description`, `og:image`, `og:url`) and Twitter card tags.
3. **Structured Data:** Valid JSON-LD schema matching page type (`WebSite`, `Organization`, `Article`, etc.).
4. **Heading Hierarchy:** Exactly one `<h1>` per view, followed by logically nested headings.
5. **Crawlability:** Valid `robots.txt` and `sitemap.xml`.
