# ENGINEERING STANDARD: FRONTEND ARCHITECTURE

## Standards
1. **Semantic HTML:** Strictly use semantic HTML5 elements (`<header>`, `<main>`, `<nav>`, `<article>`, `<section>`, `<footer>`, `<dialog>`, `<form>`).
2. **Design Token Consumption:** Use CSS custom properties mapped directly to `DESIGN_TOKENS.json`.
3. **No Dead Ends:** All navigation links and buttons must be functional or explicitly marked disabled.
4. **Type Safety:** Maintain strict TypeScript interfaces or rigorous prop validations.
