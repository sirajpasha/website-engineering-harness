# SKILL GOVERNANCE & SELECTION POLICY

## Overview
Skill governance ensures that only high-craft, verified, non-duplicative skills enter the harness ecosystem.

## Evaluation Checklist
Every new skill proposed for inclusion must pass the 10-point evaluation defined in `skills/registry/policy.md`:
1. Relevance to website engineering.
2. Codebase quality and test coverage.
3. Proven author credibility.
4. Comprehensive documentation.
5. Compatibility with Node.js 18+ and modern browser engines.
6. Clean security posture (no arbitrary code execution).
7. Zero functional overlap with existing registered skills.
8. Low token consumption footprint.
9. Concrete, measurable craft improvement.
10. Permissive open-source licensing.
