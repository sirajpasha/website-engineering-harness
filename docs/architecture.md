# SYSTEM ARCHITECTURE: UNIVERSAL WEBSITE ENGINEERING HARNESS

## 1. Architectural Philosophy
The Universal Website Engineering Harness transforms any AI coding assistant into a coordinated, multi-specialist engineering organization. The architecture is model-agnostic, enabling Claude Code, Gemini / Antigravity, OpenAI Codex / Copilot, Cursor, Windsurf, or terminal environments to collaborate seamlessly.

## 2. Structural Tiers
1. **Orchestration Tier:** Master Website Orchestrator (AGENT 01) routes user intent, manages dependencies, tracks project state across markdown specifications, and enforces the 13 Quality Gates (G1–G13).
2. **Strategy & Product Tier:** Requirement Grilling (AGENT 02) and Product Discovery (AGENT 03) eliminate ambiguity and map sitemaps and user journeys.
3. **Design & Aesthetics Tier:** Design Art Director (Taste Skill - AGENT 04), UX/UI Specialist (Impeccable - AGENT 05), and Google Stitch Design Engineer (AGENT 06) produce anti-slop visual systems and component tokens.
4. **Engineering Tier:** Frontend Architect (AGENT 08), Website Implementation Engineer (AGENT 09), and TDD Specialist (AGENT 10) build modular code using strict Red-Green-Refactor cycles.
5. **Quality, Motion & Audit Tier:** Motion Engineer (AGENT 07), Playwright Browser QA (AGENT 11), Security Auditor (AGENT 12), Web Performance Auditor (AGENT 13), SEO/Accessibility Specialist (AGENT 14), and Code Reviewer (AGENT 15).
6. **Release Governance Tier:** Production Readiness Reviewer (AGENT 16) independently audits all 12 preceding gates before issuing a release certificate.
