# WORKFLOWS REFERENCE

The harness implements 8 distinct workflows:
1. `workflows/new-website.md`: Greenfield website development (16 stages, G1–G13).
2. `workflows/existing-website-redesign.md`: Redesign existing websites, eradicating design debt.
3. `workflows/enhancement.md`: Fast-track feature addition and targeted bug fixes.
4. `workflows/tdd-development.md`: Red-Green-Refactor execution loops.
5. `workflows/browser-qa.md`: Cross-device 6-viewport automation.
6. `workflows/security-review.md`: STRIDE and OWASP Top 10 threat audits.
7. `workflows/performance-review.md`: Core Web Vitals audit and optimization.
8. `workflows/release.md`: Production gate consolidation and certification.
