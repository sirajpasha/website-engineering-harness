# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
in full, by reference.

In short: be respectful, assume good faith, critique code and ideas rather than people, and do
not harass anyone. Unacceptable behaviour can be reported privately through GitHub's
**Security → Report a vulnerability** form on this repository (it reaches the maintainer
privately), or by contacting the maintainer through their GitHub profile.

Maintainers may remove comments, commits, issues or contributors that violate this code.
